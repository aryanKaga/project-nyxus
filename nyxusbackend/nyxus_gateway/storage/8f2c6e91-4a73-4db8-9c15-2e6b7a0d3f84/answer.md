# Repository Overview & Data Processing System

This repository is a Python-based system designed for ingesting, extracting, parsing, and processing news content—with a specific focus on *Times of India* feeds and static pages. It integrates seamlessly with LLM providers and agents to process, query, and structure the data.

## Main Modules & Structure

The repository is organized into the following key directories and components:

| Module | Description |
| :--- | :--- |
| **`Ingestion/`** | Contains ingestors and parsers for content, including RSS feeds, static pages, and specialized article extractors for *Times of India*. |
| **`Agent/`** | Contains core agent logic (`agent.py`) and dynamic query generation (`query_generator.py`). |
| **`client/`** | Houses client parsers and testing utilities. |
| **`llm_provider/`** | Manages LLM integrations and models for interacting with language models. |
